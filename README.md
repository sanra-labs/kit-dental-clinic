# The Smile Studio – dental clinic website (concept)

A fast, mobile-first website for a fictional dental clinic, built by **Sanra Labs** as part of a website + ad video kit.

> Concept project: The Smile Studio, its staff, phone numbers and address are fictional. Photos are AI-generated.

**Live site:** https://kit-dental-clinic.vercel.app · **Ad video (30s):** https://youtu.be/_npCMlX0Eso

## Highlights
- Next.js 16 App Router + React 19 + TypeScript + Tailwind CSS v4
- Fully static, self-hosted variable fonts, no UI library, zero client JS outside the mobile menu
- Accessible: semantic sections, skip link, keyboard-friendly navigation, visible focus states
- schema.org `Dentist` structured data
- All copy in one content file (`src/content/site.ts`), so the kit can be rebranded in minutes

## Run locally
```bash
npm install
npm run dev
```
